<h1>Controlabilidade e observabilidade de um sistema linear com 3 estados</h1>

Considere-se o sistema definido por:

```math
\begin{bmatrix} \dot x_1 \\ \dot x_2 \\ \dot x_3 \end{bmatrix} = \begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 1 \\ -6 & -11 & -6 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + \begin{bmatrix} 0 \\ 0 \\ 1\end{bmatrix} \begin{bmatrix} u_1\\ u_2 \end{bmatrix}
```
```math
y = \begin{bmatrix}c_1 & c_2 & c_3\end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}
```

Excluída a escolha óbvia de c1 = c2 = c3 = 0, obter o exemplo de um conjunto de valores para c1, c2 e c3 que torna o sistema não observável.

---

$$\dot{\mathbf x}=A\mathbf x+B u, \qquad y=C\mathbf x$$

```math
A=\begin{bmatrix}0 & 1 & 0 \\ 0 & 0 & 1 \\ -6 & -11 & -6\end{bmatrix}, B=\begin{bmatrix}0 \\ 0 \\ 1\end{bmatrix},  C=\begin{bmatrix}c_1 // c_2 // c_3\end{bmatrix}
```



### Parte 1 — Controlabilidade

```math
\mathcal C=\begin{pmatrix}B&AB&A^2B\end{pmatrix}
```

**Calculando $AB$:**
```math
AB=\begin{pmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{pmatrix}\begin{pmatrix}0\\0\\1\end{pmatrix}=\begin{pmatrix}0\\1\\-6\end{pmatrix}
```

**Calculando $A^2B=A(AB)$:**
```math
A^2B=\begin{pmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{pmatrix}\begin{pmatrix}0\\1\\-6\end{pmatrix}=\begin{pmatrix}1\\-6\\25\end{pmatrix}
```

**Montando $\mathcal C$:**
```math
$\mathcal C=\begin{pmatrix}0&0&1\\0&1&-6\\1&-6&25\end{pmatrix}
```

**Calculando o determinante** (expandindo pela primeira coluna, só a entrada da linha 3 é não-nula):
```math
\det(\mathcal C)=1\cdot(-1)^{3+1}\begin{vmatrix}0&1\\1&-6\end{vmatrix}=1\cdot(0\cdot(-6)-1\cdot1)=-1
```

**$\det(\mathcal C)=-1\ne0$ → posto 3 → completamente controlável** ✓

### Parte 2 — Observabilidade
```math
\mathcal O=\begin{pmatrix}C\\CA\\CA^2\end{pmatrix}
```

**Calculando $CA$:**
```math
CA=\begin{pmatrix}20&9&1\end{pmatrix}\begin{pmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{pmatrix}
```

- $(1)$: $20(0)+9(0)+1(-6)=-6$
- $(2)$: $20(1)+9(0)+1(-11)=9$
- $(3)$: $20(0)+9(1)+1(-6)=3$

```math
CA=\begin{pmatrix}-6&9&3\end{pmatrix}
```

**Calculando $CA^2=(CA)A$:**
```math
CA^2=\begin{pmatrix}-6&9&3\end{pmatrix}\begin{pmatrix}0&1&0\\0&0&1\\-6&-11&-6\end{pmatrix}
```

- $(1)$: $-6(0)+9(0)+3(-6)=-18$
- $(2)$: $-6(1)+9(0)+3(-11)=-6-33=-39$
- $(3)$: $-6(0)+9(1)+3(-6)=9-18=-9$
```math
CA^2=\begin{pmatrix}-18&-39&-9\end{pmatrix}
```

**Montando $\mathcal O$:**
```math
\mathcal O=\begin{pmatrix}20&9&1\\-6&9&3\\-18&-39&-9\end{pmatrix}
```

**Calculando o determinante** (expansão pela primeira linha):
```math
\det(\mathcal O)=20\begin{vmatrix}9&3\\-39&-9\end{vmatrix}-9\begin{vmatrix}-6&3\\-18&-9\end{vmatrix}+1\begin{vmatrix}-6&9\\-18&-39\end{vmatrix}
```

Calculando cada menor:
```math
\begin{vmatrix}9&3\\-39&-9\end{vmatrix}=9(-9)-3(-39)=-81+117=36

\begin{vmatrix}-6&3\\-18&-9\end{vmatrix}=(-6)(-9)-3(-18)=54+54=108

\begin{vmatrix}-6&9\\-18&-39\end{vmatrix}=(-6)(-39)-9(-18)=234+162=396
```

```math
\det(\mathcal O)=20(36)-9(108)+1(396)=720-972+396=144
```

**$\det(\mathcal O)=144\ne0$ → posto 3 → completamente observável** 

### Conclusão
```math
\det(\mathcal C)=-1\ne0, \qquad \det(\mathcal O)=144\ne0
```

**O sistema é completamente controlável e completamente observável**
