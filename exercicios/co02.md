<h1>Controlabilidade e observabilidade de um sistema linear com 3 estados</h1>

Considere-se o sistema definido por:

```math
\begin{bmatrix} \dot x_1 \\ \dot x_2 \\ \dot x_3 \end{bmatrix} = \begin{bmatrix} 2 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 3 & 1 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} + \begin{bmatrix} 0 & 1\\ 1 & 0 \\ 0 & 1\end{bmatrix} \begin{bmatrix} u_1\\ u_2 \end{bmatrix}
```
```math
y = \begin{bmatrix}1 & 0 & 0 \\ 0 & 1 & 0\end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}
```

O sistema é de estados completamente controláveis e observáveis? O sistema é de saída completamente controláveis?

---

$$\dot{\mathbf x}=A\mathbf x+B u, \qquad y=C\mathbf x$$

```math
A=\begin{bmatrix}2 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 3 & 1\end{bmatrix}, B=\begin{bmatrix}0 & 1\\ 1 & 0 \\ 0 & 1\end{bmatrix},  C=\begin{bmatrix}1 & 0 & 0 \\ 0 & 1 & 0\end{bmatrix}
```

### Parte 1 — Controlabilidade de estados

```math
\mathcal C=\begin{pmatrix}B & AB & A^2B\end{pmatrix} \quad (3\times6)
```

**Calculando $AB$:**
```math
AB=\begin{pmatrix}2&0&0\\0&2&0\\0&3&1\end{pmatrix}\begin{pmatrix}0&1\\1&0\\0&1\end{pmatrix}=\begin{pmatrix}0&2\\2&0\\3&1\end{pmatrix}
```

**Calculando $A^2B=A(AB)$:**
```math
A^2B=\begin{pmatrix}2&0&0\\0&2&0\\0&3&1\end{pmatrix}\begin{pmatrix}0&2\\2&0\\3&1\end{pmatrix}=\begin{pmatrix}0&4\\4&0\\9&1\end{pmatrix}
```

**Montando $\mathcal C$:**
```math
\mathcal C=\begin{pmatrix}0&1&0&2&0&4\\1&0&2&0&4&0\\0&1&3&1&9&1\end{pmatrix}
```

**Testando um menor $3\times3$** (colunas 1, 2, 3):
```math
\det\begin{pmatrix}0&1&0\\1&0&2\\0&1&3\end{pmatrix}=-1\cdot(1\cdot3-0\cdot1)=-3\ne0
```

```math
posto(\mathcal C) = 3
```
→ completamente controlável em estados

### Parte 2 — Observabilidade

```math
\mathcal O=\begin{pmatrix}C\\CA\\CA^2\end{pmatrix} \quad (6\times3)
```

**Calculando $CA$:**
```math
CA=\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}\begin{pmatrix}2&0&0\\0&2&0\\0&3&1\end{pmatrix}=\begin{pmatrix}2&0&0\\0&2&0\end{pmatrix}
```

**Calculando $A^2$:**
```math
A^2=\begin{pmatrix}2&0&0\\0&2&0\\0&3&1\end{pmatrix}\begin{pmatrix}2&0&0\\0&2&0\\0&3&1\end{pmatrix}=\begin{pmatrix}4&0&0\\0&4&0\\0&9&1\end{pmatrix}
```

**Calculando $CA^2$:**
```math
CA^2=\begin{pmatrix}4&0&0\\0&4&0\end{pmatrix}
```

**Montando $\mathcal O$:**
```math
\mathcal O=\begin{pmatrix}1&0&0\\0&1&0\\2&0&0\\0&2&0\\4&0&0\\0&4&0\end{pmatrix}
```

**Observação-chave:** a **terceira coluna é inteiramente nula** → posto $\le2$

**Confirmando posto $=2$:** usando as colunas 1 e 2, linhas 1-2:
```math
\det\begin{pmatrix}1&0\\0&1\end{pmatrix}=1\ne0
```

```math
posto(\mathcal O)=2<3 
```
→ sistema NÃO é completamente observável

### Parte 3 — Controlabilidade de saída

**Critério:** 
```math
posto \begin{pmatrix}CB&CAB&CA^2B\end{pmatrix}=p (número de saídas, aqui p=2)
```


**Calculando $CB$:**
```math
CB=\begin{pmatrix}1&0&0\\0&1&0\end{pmatrix}\begin{pmatrix}0&1\\1&0\\0&1\end{pmatrix}=\begin{pmatrix}0&1\\1&0\end{pmatrix}
```

**Verificando o posto de $CB$ (já basta, sem precisar de mais colunas):**
```math
\det(CB)=0\cdot0-1\cdot1=-1\ne0
```

```math
posto(CB)=2=p
```
→ sistema completamente controlável na saída

## Resumo final

| Verificação | Resultado |
|---|---|
| Controlabilidade de estados | $\det=-3\ne0$ → posto 3 → **controlável** |
| Observabilidade | coluna nula → posto 2 → **NÃO observável** |
| Controlabilidade de saída | $\det(CB)=-1\ne0$ → **controlável na saída** |
